Customization

Reback is highly customizable and provides an easy way to change the layouts, color themes etc. Reback comes with different layout choices, including vertical and horizontal. The layout and left sidebar related customization can be done by simply changing the value of a few state variables. Everything is being controlled through Redux. Please refer to below described details in order to see what are the possible customization or changes.

And for Customizing in existing themes, open the layout-reducer.ts file from src/app/store/layout/layout-reducer.ts and change in IntialState like below.

Title Type Options Description
LAYOUT String "LAYOUT_TYPES.VERTICAL" | "LAYOUT_TYPES.HORIZONTAL" Changes overall layout
LAYOUT_THEME String "LAYOUT_COLOR_TYPES.LIGHTMODE" | "LAYOUT_COLOR_TYPES.DARKMODE" Changes overall color scheme to dark
LAYOUT_MODE String "LAYOUT_MODE_TYPES.FLUID" | "LAYOUT_MODE_TYPES.BOXED" Changes the width of overall layout
LAYOUT_TOPBAR_COLOR String "LAYOUT_TOPBAR_COLOR_TYPES.LIGHTMODE" | "LAYOUT_TOPBAR_COLOR_TYPES.DARKMODE" the Topbar color scheme.
LAYOUT_MENU_COLOR String "LAYOUT_MENU_COLOR.LIGHTMODE" | "LAYOUT_MENU_COLOR.DARKMODE" the left sidebar color scheme.
LAYOUT_MENU_SIZE String "LAYOUT_MENU_SIZE.DEFAULT" | "LAYOUT_MENU_SIZE.COMPACT" | "LAYOUT_MENU_SIZE.CONDENSED" |" LAYOUT_MENU_SIZE.FULL" the left sidebar size changes to small (condensed)
LAYOUT_POSITION String "LAYOUT_POSITION_TYPES.FIXED" | "LAYOUT_POSITION_TYPES.SCROLLABLE" Layout Position
