Introduction

Reback is a fully featured premium admin template built on top of awesome Angular 19 & Bootstrap 5.3.5. It's crafted using modern web technologies Angular, CSS3 and Typescript. The theme includes beautiful dashboard, many ready to use hand crafted components, widgets, pages, etc. The components can be used very easily on any page. The theme is fully responsive and customizable.

It is extremely powerful and adaptable, making it ideal for web development. applications including CRM, CMS, admin panels, dashboards, etc. It is fully responsive and has a perfect look and feel on mobiles and tablets. Also, we tried to implement this by Keeping the concept of modularity in mind, this enables you to reduce the development time and cost.

This documentation is guidelines for all users who can even be a beginner or experienced web developer.

Structure

When you extract the zip file you received after purchasing, you will find the following files and folders: 

                                    
                                      ├── docs
                                      ├── Reback
                                      │   ├── public                            // Contain assets folder
                                      │   ├── src/                   
                                      │   │   └── app          
                                      │   │   │   └── common                    // All common Data & Model files
                                      │   │   │   └── components                  // All common component
                                      │   │   │   └── core                      // The core module - mainly contains the common services (singleton ones)
                                      │   │   │   └── layouts                    // All layouts here
                                      │   │   │   └── store                    // The store module - containing ngrx store files
                                      │   │   │   └── views                    // containing implementation of all pages including, ui kits, widgets, forms, dashboards, tables, charts, etc
                                      │   │   │   └── app.component.html     // Contain top loading bar and back to top
                                      │   │   │   └── app.component.scss     // scss style files
                                      │   │   │   └── app.component.spec.ts    // Testing File
                                      │   │   │   └── app.component.ts    // Entry point component
                                      │   │   │   └── app.config.ts    // Main config for application
                                      │   │   │   └── app.routes.ts  // Router implementation
                                      │   │   └── globals.d.ts    
                                      │   │   └── index.html     // Entry point of an Angular application
                                      │   │   └── main.ts     // This file bootstraps (starts) the AppModule from app. module.
                                      │   │   └── styles.scss   // Common Scss file
                                      │   ├── .editorconfig   //Contain file format for defining coding styles and a collection of text editor plugins
                                      │   ├── .gitignore   // Contains list of files or directories which are not supposed to be included in git commit
                                      │   ├── .prettierrc   //Contains Prettier's configuration for code formatting. It enforces a consistent style by parsing your code and re-printing it with its own rules
                                      │   ├── angular.json    // Project based configuration file
                                      │   ├── package-lock.json    //npm Lock dependencies to a specific version number to avoid possible version mismatch.
                                      │   ├── package.json   // Package json file
                                      │   ├── README.md  // Introductory documentation
                                      │   ├── tsconfig.app.json   //ensuring proper compilation and execution of test code within the projec                
                                      │   ├── tsconfig.json   // Contains the configuration for how the typescript is supposed to work/behave for your current project                 
                                      │   ├── tsconfig.spec.json   //configures TypeScript settings specifically for unit test files (*.spec.ts)                
                                      │   ├── yarn.lock   //yarn Lock dependencies to a specific version number to avoid possible version mismatch.
